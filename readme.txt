FREE AI TOOL — WEBSITE FILES
============================

Included:
- index.html       Main website
- styles.css       Responsive styling
- script.js        Search, category filters, tool cards, and usage-guide dialogs

Preview locally:
1. Extract this ZIP.
2. Open index.html in a modern browser.

Publish free with Netlify:
1. Create/sign in to a Netlify account at https://www.netlify.com/
2. Open the Netlify dashboard and choose the option to add/deploy a new site using manual deploy (the label may change).
3. Drag the extracted folder (the folder containing index.html, styles.css, and script.js) into the deploy area.
4. Wait for the deployment to finish and open the assigned *.netlify.app address.
5. In site settings, you may change the site name if the desired name is available.

Domain note:
A permanent custom .com domain normally requires paid registration. Free hosting does not automatically provide free ownership of free-ai-tool.com. You can connect a domain later after registering it.

Important:
- The directory is a starter site with 13 example listings.
- Free-plan details can change; each listing reminds visitors to check the official provider.
- Review every listing before publishing. Add your own privacy/contact pages if you later add analytics, user submissions, or monetisation.
- The sample contact email uses a reserved .example domain and is not a working mailbox. Replace it with your real contact email or remove the suggestion link.
